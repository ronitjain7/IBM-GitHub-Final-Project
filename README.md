# Simple Interest Calculator

A simple project to calculate simple interest using the principal amount, annual rate of interest, and time period.

## Description

This project demonstrates the fundamentals of Git and GitHub through a simple interest calculation script.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Inputs

- **p:** Principal amount
- **t:** Time period
- **r:** Annual rate of interest

## Output

The calculated simple interest for the given inputs.
